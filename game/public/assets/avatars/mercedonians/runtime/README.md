# Mercedonian runtime avatars

These nine animated citizens are optimized copies of the original uploaded GLBs. The source files remain untouched one directory above.

- 256px WebP textures
- Meshopt-compressed geometry
- 8k–15k triangles per citizen
- `Idle` and `Walk` animations preserved
- Integrity and performance budgets recorded in `manifest.json`

Rebuild with `node scripts/worldgen/mercedonians/optimize_mercedonian_avatars.mjs`.
