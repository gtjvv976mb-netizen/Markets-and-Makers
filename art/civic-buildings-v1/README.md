# Markets & Makers civic buildings v1

This folder is the authoring contract for the new civic building package. It does not replace or modify anything in `art/official-v1`.

The kit contains nine public structures: City Hall, Treasury, Land Registry, Transit Hall, Community Clinic, Rescue Station, Public Works Depot, Maker Academy and Garden Commons housing. The already-approved Public Market Pavilion remains the market authority and is deliberately not duplicated here.

Generate the editable Blender and GLB package with `work/create_markets_makers_civic_buildings_v1.py`, then run `work/validate_markets_makers_civic_buildings_v1.py`. Promote this specification to the official library only after both visual and technical QA pass.
